# SnapGrid: Block Puzzle

Offline-first Android block-drop puzzle game built with Flutter.

## Features
- **8x8 Cozy Neon Arcade Grid** with tactile 3D jewel blocks and white/gold line-clear previews.
- **1 Free Hold / Swap Bank Slot** (plus a temporary 2nd Hold Slot unlocked via Rewarded Ad).
- **Combo Bomb Tile:** Every 10 combos earned drops a Bomb Tile that blasts any 3x3 square on the board.
- **100% Offline Gameplay:** Local high score, active board progress, sound effects (`.wav`), and haptic feedback.
- **Google AdMob Ready:** Configured with official Test Ad IDs and UMP privacy consent.

## Run & Test
```bash
flutter analyze
flutter test
flutter run
```
